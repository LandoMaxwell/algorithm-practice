## 💡 解题特点

- **清晰的注释**：每个算法都包含详细的中文注释，解释思路和实现细节
- **完整的测试**：提供多种测试用例，包括边界条件和性能测试

- **复杂度分析**：包含时间复杂度和空间复杂度分析

## 🚀 如何使用

### 运行 Python 题目
```bash
# 运行根目录的 LeetCode 题目
python "2.两数相加.py"

# 运行 python/ 目录下的算法
python python/binary_tree_inorder_traversal.py
python python/merge_intervals.py
```

### 编译 C++ 竞赛题目
```bash
g++ -O2 -o a cpp/a.cpp
./a
```

## 🎯 学习建议

1. **理解思路**：先阅读代码注释，理解算法思路
2. **运行测试**：执行文件查看测试用例和结果
3. **动手实践**：尝试自己实现，然后对比优化
4. **举一反三**：思考类似问题的解决方法
